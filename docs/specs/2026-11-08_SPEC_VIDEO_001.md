## 3. Arquitetura (DAG)
| Nó | Tipo | Comando | Saída (gate) |
| :-- | :-- | :-- | :-- |
| `n01_extrair_audio` | script | `ffmpeg -i raw -vn -ar 16000 -ac 1 audio.wav` | `file_exists(audio.wav)` |
| `n02_transcrever` | script | `whisper-cli -m <modelo> -f audio.wav -ojf` | `file_exists(audio.json)` com tempos por palavra |
| `n03_alinhar_roteiro` | script | casa roteiro × palavras e gera `segmentos.json` | JSON válido, todo trecho do roteiro mapeado |
| `n04_plano_cenas` | agent | plano cena por cena em `plano.md` | arquivo existe |
| `n05_gate_plano` | human_gate | operador aprova ou corrige `plano.md` | aprovação registrada |
| `n06_renderizar_cenas` | script | `hyperframes render` por cena | MP4 por cena em `scratch/cenas/` |
| `n07_montar` | script | `ffmpeg` com cortes de `segmentos.json` + overlays das cenas | `final.mp4` 1080p60 |
| `n08_verificar` | script | `ffprobe` valida resolução, fps, duração e áudio | exit 0 |

Costura de teste: `n03` é função pura (roteiro + palavras → segmentos) e deve ter teste de unidade; os demais nós são verificados por gate de artefato.

## 4. Contratos de Dados
* `segmentos.json`: lista de `{ id, texto, inicio_ms, fim_ms, cena? }`; `fim_ms > inicio_ms`; sem sobreposição.
* `plano.md`: uma seção por cena com `id`, trecho do roteiro, estilo e duração.
* Referência de estilo: caminho opcional `var.video_referencia`.

## 5. Critérios Binários de Aceite (BDD)
* [ ] `AC-1` **Transcrição local.** Dado `raw.mp4` com fala, quando `n01` e `n02` rodam, então existe `audio.json` com tempos por palavra e nenhuma conexão de rede é aberta.
* [ ] `AC-2` **Alinhamento.** Dado um roteiro de 5 falas e o `audio.json`, quando `n03` roda, então `segmentos.json` tem 5 itens, ordenados e sem sobreposição.
* [ ] `AC-3` **Plano antes do render.** Dado `plano.md` sem aprovação, quando o DAG tenta executar `n06`, então a execução para em `n05`.
* [ ] `AC-4` **Render local.** Dado um plano aprovado, quando `n06` roda, então cada cena gera um MP4 em `scratch/cenas/` sem chamar serviço externo.
* [ ] `AC-5` **Golden Fixture.** Dado o fixture de 3s, quando o DAG roda de ponta a ponta, então `final.mp4` tem 1920x1080, 60 fps e duração de 3,0 s ± 0,1 s.
* [ ] `AC-6` **Custo zero.** O DAG não contém nó com comando para domínio externo pago (HeyGen, ElevenLabs, Higgsfield); verificado por grep no `pipeline.dag.json`.
* [ ] `AC-7` **Validação do DAG.** `legoloop validate loops/video-001/pipeline.dag.json` retorna exit 0.
