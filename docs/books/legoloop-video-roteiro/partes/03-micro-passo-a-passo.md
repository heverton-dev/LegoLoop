# Operação Passo a Passo

1. Validar contratos: `legoloop video-roteiro validar-config --projeto <DIR> --json`.
2. Executar pré-voo modular: `legoloop video-roteiro prevoo --projeto <DIR> --json`.
3. Coletar pautas inéditas: `legoloop video-roteiro coletar --projeto <DIR> --json`.
4. Validar roteiro epistêmico: `legoloop video-roteiro validar-roteiro --projeto <DIR> --json`.
