# Parte IV: Guia do Operador Leigo

## Capítulo 4: Operando a Fábrica no Modo Autopilot

Com a flag `--ui autopilot`, o LegoLoop traduz complexidades de código para decisões gerenciais transparentes.

```
📋 [CARTÃO DE DECISÃO EXECUTIVO // MODO AUTOPILOT]
· Ação:           Aprovação da Curadoria de Peças
· Resumo Simples: O pipeline identificou 3 ferramentas gratuitas que substituem APIs pagas.
· Tempo Previsto: 1m 30s
· Custo Estimado: $0.00 (100% Soberano)

Deseja autorizar esta etapa? [Sim/Não]: 
```

O operador não visualiza stacks de código, ponteiros ou árvores sintáticas. Ele avalia apenas a ação pretendida, o tempo necessário e o custo projetado, autorizando o avanço com uma resposta binária.
