# Operação Passo a Passo

1. Validar contratos: `legoloop diorama-roteiro validar-config --projeto <DIR> --json`.
2. Executar pré-voo modular: `legoloop diorama-roteiro prevoo --projeto <DIR> --json`.
3. Coletar pautas inéditas: `legoloop diorama-roteiro coletar --projeto <DIR> --json`.
4. Validar roteiro epistêmico: `legoloop diorama-roteiro validar-roteiro --projeto <DIR> --json`.
