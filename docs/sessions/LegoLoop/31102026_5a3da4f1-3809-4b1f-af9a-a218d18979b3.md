## 2. A "esteira real", explicada

A clínica veterinária **não é um personagem nem um projeto existente**. É só a **ideia de entrada**, uma frase que passei na linha de comando: *"App web para uma clínica veterinária agendar consultas, enviar lembretes por WhatsApp e manter o prontuário dos pets"*.

A partir dessa frase, o LegoLoop executou uma cadeia de "peças". Cada peça é **uma chamada a um modelo de IA, isolada das outras**: ela só lê o arquivo que a peça anterior gravou e grava o seu.

1. **interview:** a frase vira `BRIEFING.md`, com problema, público e funcionalidades.
2. **aidd-spec:** lê o BRIEFING e escreve `SPEC.md`, com critérios de aceitação. Ao mesmo tempo, **riscos** lê o mesmo BRIEFING e escreve `RISCOS.md`.
3. **check:** um script local extrai o checklist da SPEC para `CHECKLIST.txt`.

Cada peça só libera a próxima se passar no seu "gate". Por exemplo, a SPEC precisa ter a seção "Critérios de Aceitação".

Deixei tudo no projeto para você abrir: [examples/clinica-veterinaria/LEIAME.md](examples/clinica-veterinaria/LEIAME.md) explica passo a passo, e a pasta `saida/` tem os arquivos que a IA gerou de verdade.

## 3. Como acessar a interface (o Looping Studio)

Ela está **aberta agora** no painel do navegador ao lado, em `http://localhost:7878`. Deixei uma rota traçada (Interview → AIDD Spec), já validada, e o 9Router aparece online com os combos no topo.

Para abrir de novo depois, rode no terminal, dentro da pasta do projeto:
```bash
bin\legoloop.exe studio --project examples\meu-projeto
```
Depois acesse `http://localhost:7878` no navegador.

**O que dá para fazer na interface:**
- **Montar a esteira:** arraste blocos da lateral para o canvas e ligue a saída de um à entrada de outro, puxando pela bolinha da direita.
- **Configurar cada bloco:** clique nele e escolha no inspetor o modo Sugerido, Manual ou Auto e o modelo.
- **Botões:** "Validar" confere os encaixes, e "Materializar Esteira" grava o `pipeline.dag.json` em `examples/meu-projeto`.

Uma observação: os combos do 9Router só aparecem se as variáveis `NINEROUTER_URL` e `NINEROUTER_KEY` estiverem no ambiente. Como você usou `setx`, basta abrir um **terminal novo**.
