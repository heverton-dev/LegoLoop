## Dois pontos para checar

**1. O que o "Canonizar" faz de fato.** Ele **não** padroniza tudo.
- Só unifica duplicatas **exatas** (mesmo SHA-256). Variantes nunca são sobrescritas.

Se você quer que ele também resolva variantes, ou que crie symlink mesmo sem admin (por exemplo, pedindo elevação), isso é uma decisão nova. Sugiro manter assim e deixar a UI explicar esses limites, com o botão em modo **simular** antes de **aplicar**.
