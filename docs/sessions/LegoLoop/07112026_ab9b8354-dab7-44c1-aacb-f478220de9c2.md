### 2. Como cada Ação/Verbo opera no LegoLoop

* **Mudar / Editar:**  
  * Via comando: `legoloop refinar` substitui um nó específico preservando os contratos adjacentes.

  * `legoloop compor` injeta um novo sub-loop ou ferramenta em qualquer posição (`--pos N`) do fluxo sem quebrar o DAG existente.
* **Remover / Podar:**  
  * `legoloop remover` desconecta o nó ou processo, limpa vínculos nos harnesses (Claude, Cursor, Windsurf, MIMO) e oferece rollback seguro.
* **Melhorar / Evoluir:**  
  * A **Matriz de Peças** (`legoloop matriz`) avalia continuamente a reputação das peças (Ouro, Prata, Bronze). Você pode trocar uma peça defasada por uma versão Padrão Ouro sem alterar o pipeline.
