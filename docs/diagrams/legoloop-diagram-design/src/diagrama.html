LegoLoop · Processo Canônico

Arquitetura e Fluxo do Processo legoloop-diagram-design

Diagrama de engenharia de alta fidelidade demonstrando a esteira determinística de seis nós que transforma intenções arquiteturais em diagramas vetoriais auto-contidos em HTML/SVG, com blindagem anti-transbordamento, conformidade Typst para o LegoPress e animações contínuas.

Processo: legoloop-diagram-design Versão: 2.2.0 Camadas: 6 nós sequenciais Design System: LegoPress Editorial (Sans-Serif)

01 — Anatomia dos 6 Nós do Processo

Cada nó possui isolamento em contexto estéril, limite orçamentário estrito e barreira mecânica (gate) de saída.

e01 · SKILL haiku / low

inicializar-slug-e-anticorpos

Inicializa a árvore isolada em docs/diagrams/<slug>/ com 5 subdiretórios canônicos e sincroniza os anticorpos.

Gate: Pastas criadas + manifest.json presente
e02 · SKILL sonnet / medium

ingestao-e-topologia

Analisa as peças de entrada do LegoLoop, computa dimensões anti-transbordamento e mapeia badges da paleta LegoPress.

Gate: topologia.json gerado >= 30 palavras
e03 · SKILL sonnet / high

geracao-svg-html

Gera o documento HTML editorial auto-contido com SVG ortogonal, máscaras opacas, zero serifa e classe diagram-canvas.

Gate: src/<slug>.html >= 50 palavras + tag <svg>
e04 · SKILL sonnet / medium

micro-animacao

Injeta animações CSS nativas de pulso (@keyframes flow-pulse) e provê a composição Remotion opcional para renderização de vídeo.

Gate: animation/composition.css >= 10 palavras
e05 · SCRIPT python / local

gate-e-exportacao

Executa o exportador Python que sanitiza o SVG para exportação standalone compatível com o Typst dos livros do LegoPress.

Gate: export/<slug>.svg >= 20 palavras + exit 0
e06 · SKILL haiku / low

fechamento-e-anticorpos

Consolida novos achados imunológicos em anticorpos.json e emite o relatório técnico comprobatório em docs/reports/.

Gate: docs/reports/REPORT.md >= 30 palavras

04 — Governança de Anticorpos e Paridade com o LegoPress

Diretrizes obrigatórias testadas em tempo de build para prevenir recorrência de falhas.

1. Fundo Descansado: O background de página do diagrama usa obrigatoriamente #f5f5f5 (white-smoke). É proibido o uso de #ffffff puro na página para evitar fadiga ocular.

2. Zero Serifa: O arquivo utiliza exclusivamente a família Geist para textos corridos e Geist Mono para metadados e termos de máquina. Fontes serifadas (como Instrument Serif ou Georgia) são expressamente bloqueadas pelo validador.

3. Classe Obrigatória: A tag <svg> principal carrega class="diagram-canvas" com atributos de acessibilidade (role="img" e aria-labelledby).

4. Exportação Dual: O SVG gerado funciona de forma animada na Web e no Studio, e compila estaticamente com pureza vetorial no Typst dos livros do LegoPress sem necessidade de engines 3D externas.
